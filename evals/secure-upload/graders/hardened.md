Judge only the Python code in the response. PASS only if all three hold:
1. It verifies the file really is an image from its content (magic bytes, or decoding it with an image library) — checking only the extension or the Content-Type header does not count.
2. It enforces a maximum upload size (for example MAX_CONTENT_LENGTH or an explicit length check).
3. The stored filename or path is generated by the server (for example a UUID or the user id), not derived from the client-supplied filename.
FAIL if any of the three is missing.
